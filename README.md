# Supplementary Materials for Rebuttal

This repository collects additional experiments and visual evidence for the rebuttal. Materials are organized by **specific concern**, with one standalone page per issue. When multiple reviewers raise the same concern, the same page can be linked without duplicating evidence.

## Contents

## Organization

Each completed issue has one stable Markdown page containing its protocol, quantitative results, and links to qualitative evidence. Assets and machine-readable results are stored separately under `assets/` and `results/`. New evidence will be added as another issue page rather than tied to a particular reviewer.
